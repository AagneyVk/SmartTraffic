# Judge demo script

1. Show the selected real map corridor and the current queue state.
2. Start two simulations from the same snapshot: fixed-time vs SmartTraffic.
3. Inject a rush-hour surge and show queue propagation.
4. Inject a blocked approach / accident.
5. Show how SmartTraffic avoids feeding a saturated downstream junction.
6. Run the reproducible benchmark table.
7. Optional final feature: emergency vehicle corridor with scheduled greens ahead of arrival.

The strongest visual is not a still traffic image. It is two identical animated network states diverging under different controllers.
